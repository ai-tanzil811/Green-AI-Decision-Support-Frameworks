# Results Directory

This directory is organized by purpose so benchmark outputs are easy to browse without mixing verified results, working files, archives, and caches.

## Start Here

| Folder | Purpose |
| --- | --- |
| [canonical_benchmark](canonical_benchmark) | Verified source of truth for the 60-run benchmark. Use this for analysis, reports, and future model development. |
| [working_run](working_run) | Working dataset, duplicate exports, intermediate outputs, and the original benchmark archive. |
| [notebook_assets](notebook_assets) | Files generated by notebook rendering or execution support. |
| [cache](cache) | Download/cache metadata. It is not benchmark evidence. |

## Canonical Benchmark

Use [canonical_benchmark](canonical_benchmark) for the cleanest access path:

- [configs](canonical_benchmark/configs): backbone, task, and PEFT method YAML files.
- [raw_runs](canonical_benchmark/raw_runs): one JSON record per attempted run, including successful and OOM statuses.
- [metrics](canonical_benchmark/metrics): aggregate, scored, GEI, Pareto, and sweep CSV files.
- [figures](canonical_benchmark/figures): benchmark visualizations.
- [manifest.json](canonical_benchmark/manifest.json): platform, grid, seed, and scoring metadata.

### Metric files

- [aggregated.csv](canonical_benchmark/metrics/aggregated.csv): feasible configurations with means and standard deviations.
- [aggregated_scored.csv](canonical_benchmark/metrics/aggregated_scored.csv): alternative preference profiles.
- [aggregated_gei.csv](canonical_benchmark/metrics/aggregated_gei.csv): GEI results.
- [pareto_fronts.csv](canonical_benchmark/metrics/pareto_fronts.csv): non-dominated configurations.
- [sweep_raw.csv](canonical_benchmark/metrics/sweep_raw.csv): raw sweep summary.

## Working Run

[working_run](working_run) retains material from the original project layout:

- `configs/`: working configuration copies.
- `data/`: downloaded or prepared dataset assets.
- `raw_runs/`: working raw-run copies.
- `metrics/`: working aggregate outputs.
- `figures/`: working figures.
- `archives/export_bundle/`: the exported bundle with its original internal structure.
- `archives/sustainable_peft_benchmark_bundle.zip`: original compressed bundle.

Use the canonical folder for new analysis. Use the working folder when reproducing or inspecting the original export process.
